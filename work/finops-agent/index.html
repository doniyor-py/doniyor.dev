FinOps Agent

Built at Cursor Hack London · 30 Apr 2026

  • FastAPI
  • Claude API
  • JWT
  • bcrypt
  • WebSockets
  • SQLAlchemy 2
  • SQLite
  • APScheduler
  • React
  • Vite

FinOps Agent (repo name: Finoks) treats receivables as a guarded workflow rather than a single prompt. It chases late invoices, screens counterparties for AML risk and applies UK Late Payment Act statutory interest.

Overdue invoices progress through deterministic rules, counterparty enrichment and a three-tier autonomy gate (AUTO / ESCALATE / HARD_BLOCK), so risky actions never go out without escalation.

How it works

  • FastAPI backend with JWT auth and bcrypt-hashed passwords; scheduled runs via APScheduler.
  • Claude drafts chaser emails, with template fallbacks when no API key is set.
  • The agent’s activity feed streams to a React UI over a WebSocket.
  • Seeded demo invoices exercise every branch of the autonomy gate.

Compliance framing

The backend sets compliance context (POCA 2002, MLR 2017, FCA FCG, NCA typologies and the Late Payment of Commercial Debts (Interest) Act 1998) beside the mechanics, so every decision the agent makes can be traced to a rule.
