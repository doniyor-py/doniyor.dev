FinOps Agent

Hackathon

Autonomous accounts-receivable agent built at a London fintech hackathon ([TODO: hackathon name and date]).

Problem
Small UK businesses lose time and cash chasing late invoices, and letting an LLM act freely on financial decisions isn’t safe.
Built
A FastAPI agent that chases overdue invoices, screens counterparties for AML risk and applies UK Late Payment Act interest. Every action passes a three-tier autonomy gate (AUTO / ESCALATE / HARD_BLOCK), Claude drafts the emails, and the activity feed streams live over WebSockets behind JWT + bcrypt auth.

FitFlow

Deployed

AI fitness-coaching bot on Telegram.

Problem
Generic training advice ignores the workouts you’ve actually done, and that data sits scattered across fitness apps.
Built
A Telegram bot that syncs Strava activities through OAuth2 into Supabase, then answers free-text questions with Claude using recent training as context, so the coaching is grounded in real data. Dockerised and deployed on Render.
Stack
  • Claude API
  • Supabase
  • Strava OAuth2
  • TypeScript
  • Docker
  • Render
