Case study

FitFlow

AI fitness-coaching bot on Telegram · Deployed on Render

  • Claude API
  • Supabase
  • Strava OAuth2
  • TypeScript
  • Node.js
  • Telegram Bot API
  • Docker
  • Render

A Telegram-first assistant that pulls normalised workout data into Supabase and routes free-text questions to Claude with recent activity as context, so answers are grounded in your training rather than generic advice.

How it works

  • /connect strava starts an OAuth2 flow; /today syncs the latest activities.
  • Any plain-text message goes to Claude along with recent workouts.
  • Oura and TrainingPeaks adapters are scaffolded with OAuth and token persistence.
  • Garmin has no public OAuth for individuals, so it uses an unofficial library with credentials encrypted at rest.
  • Dockerised; on deploy, the service registers its Telegram webhook on start-up.
