Earlier data work

London bike journey analysis

Santander Cycles · Dataset: August 2023 · Built March 2026

  • R
  • RStudio
  • R Markdown
  • ggplot2

Findings

  • The median trip lasts about 14 minutes, and weekend journeys run longer than weekday ones, suggesting a shift from commuting to leisure.
  • A small number of central London stations dominate demand, particularly near major transport hubs and tourist areas.
  • Weekdays show a double peak (8–9am and 5–6pm); weekends show a flatter, midday-centred curve.

These insights could help TfL optimise bike redistribution, prioritise dock maintenance and plan capacity for peak periods. The work is written up as a knitted R Markdown report with reproducible code and charts.
