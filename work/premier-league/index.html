Earlier data work

Premier League performance analysis

Match data 2023/24 – 2025/26 · Built 2025–2026

  • Python 3.12
  • Pandas
  • NumPy
  • Matplotlib
  • Seaborn
  • Jupyter

I picked football because every row is a story: a result is already a structured experiment in tactics, luck and sample size. Three seasons of Premier League fixtures (from football-data.co.uk) gave me enough volume to build a credible league table from scratch, stress-test aggregations, and still keep the narrative grounded for non-technical readers.

The pipeline loads and cleans multi-season CSVs, merges seasons consistently, then moves into EDA: home vs away splits, goal trends, the correlation between shots on target and goals, and team-level leaderboards. The outputs live as a chart library in the repo, including extremes like the biggest margin wins and defensive consistency (clean sheets).
