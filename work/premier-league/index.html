Earlier data work

Premier League performance analysis

Match data 2023/24 – 2025/26 · Built 2025–2026

  • Python 3.12
  • Pandas
  • NumPy
  • Matplotlib
  • Seaborn
  • Jupyter

I picked football because every result is already a structured experiment in tactics, luck and sample size. Three seasons of Premier League fixtures (from football-data.co.uk) gave me enough volume to build a credible league table from scratch.

The pipeline

  • Load and clean multi-season CSVs, then merge seasons consistently.
  • EDA: home vs away splits, goal trends, and the correlation between shots on target and goals.
  • Team-level leaderboards and a chart library, including the biggest margin wins and clean sheets.
